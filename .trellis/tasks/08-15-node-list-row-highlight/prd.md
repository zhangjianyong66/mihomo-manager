# 增强节点列表当前行高亮

## Goal

提高 TUI“节点管理 > 节点切换列表”中键盘光标的可辨识度，让用户在较宽终端和长节点列表中能立即看清即将操作的节点。

## Background

- 节点列表当前只在光标行前显示 `> `，宽终端下不易追踪整行位置。
- `internal/tui/model.go` 中光标索引 `actionIndex` 与当前已启用节点 `currentNodeName` 是两个独立状态。
- 当前已启用节点继续由节点名后的 `✅` 表示；本任务的背景高亮用于键盘光标行，不能混淆二者。
- 节点行已经按终端宽度对节点名、测速状态和填充空格进行布局，窄终端有不越界的回归测试。

## Requirements

- R1：仅在节点切换列表中，为键盘光标所在行增加连续背景色，使节点名到右侧测速状态形成一条可辨识的高亮带。
- R2：上下移动光标时，高亮必须同步移动；按 Enter 切换节点后，光标高亮与 `✅` 各自表达原有状态。
- R3：高亮状态下节点名、`✅`、延迟或失败状态仍应清晰可读。
- R4：不得改变节点选择、测速、分页、截断、daemon 能力调用或其他 TUI 页面行为。
- R5：高亮行不得超出当前节点列表既有可用宽度，在窄终端和宽终端下均保持稳定布局。

## Key Decisions

- 光标行使用深青蓝背景配白色前景，以在深色终端中提供明确对比。
- 背景色覆盖节点内容区的整行；`>` 保持作为辅助光标标记。
- 高亮只作用于“节点管理 > 节点切换列表”，不扩展到其他菜单。

## Acceptance Criteria

- [x] AC1：进入节点切换列表后，当前光标行显示一条覆盖整条节点内容区的连续背景色，而非仅给 `>` 或节点名着色。
- [x] AC2：按上/下方向键后，旧行恢复普通样式，新光标行获得背景高亮。
- [x] AC3：光标停在当前已启用节点或其他节点时，用户都能同时区分“光标所在行”和带 `✅` 的“当前已启用节点”。
- [x] AC4：高亮行中的节点名及 `[未测速]`、成功延迟、失败状态保持可读，且显示宽度不超过现有节点行约束。
- [x] AC5：节点列表相关测试覆盖高亮作用域、移动和窄终端宽度；`go test ./internal/tui` 与 `go test ./...` 通过。

## Out of Scope

- 不改变当前已启用节点的 `✅` 标记。
- 不调整节点列表数据、排序、分页、测速或选择逻辑。
- 不为主菜单、代理组列表或其他操作菜单统一增加背景高亮。

## Notes

- 这是局限在 `internal/tui` 渲染与测试的轻量任务，规划阶段使用 PRD 即可。
