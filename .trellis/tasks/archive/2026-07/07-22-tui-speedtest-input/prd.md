# 修复 TUI 连续与批量测速按键响应

## Goal

修复 TUI“节点管理 > 节点切换列表”的显式测速交互：单节点测速未完成时，用户仍可通过 `t` 把其他节点加入串行队列；`a` 始终能清空单测队列并立即切换为整组批量测速。界面必须即时反馈按键已生效。

## Background

- 2026-07-22 用户实测：按 `t` 发起单节点测速后，在当前测速未完成时继续按 `t` 无法触发下一个测试；按 `a` 批量测速也没有可见反应。
- 当前 TUI 使用独立的 `nodeTestActive`、cancel 和 generation，键盘分发未显式锁定 `t`/`a`，但既有“取消并替换”行为始终显示相同的“测速中”，无法满足连续单测需求，也缺少能证明阻塞时序的测试。
- `app.DaemonCapabilities.TestNodes` 已在 goroutine 内打开和消费 daemon 流，TUI capability 调用由 `tea.Cmd` 延迟执行；本次不需要改变 daemon、IPC 或 mihomo `/delay` 契约。
- 用户已确认采用推荐方案：当前单测继续，新选中的节点进入串行队列；`a` 清空队列并切换批量。

## Requirements

- R1：节点测速进行中，节点列表必须继续响应方向键、`t`、`a` 和 `Esc`，不得复用通用 `busy` 输入锁。
- R2：空闲时按 `t`，立即开始光标所在可测速节点的单测；单测进行中按 `t`，把此时光标节点加入有序串行队列，不取消当前单测。
- R3：当前正在测试或已经排队的节点不得重复入队；界面应提示该节点已在测速或队列中。用户移到其他节点后再按 `t` 才加入下一个节点，`t` 不自动移动光标。
- R4：一项单测正常完成后，自动启动队首节点；队列为空后进入空闲状态。单节点失败/超时作为正常结果继续下一项，系统性 stream 错误停止队列并显示错误。
- R5：任意测速状态下按 `a`，清空单测队列、取消当前流，并以新 generation 立即启动当前代理组完整批量测速；请求保持 `concurrency=5`、`limit=0`。
- R6：批量测速中按 `t`，取消批量并立即启动光标节点的单测；批量测速中再次按 `a`，取消并重新开始整组批量测速。
- R7：每次取消、替换或启动下一条流都使用新的 generation；旧流迟到的 started、结果、完成、关闭或错误消息不得修改当前状态。
- R8：已完成的测速结果在排队、切换模式和取消时保留，新结果按节点 ID 覆盖；测速不得隐式切换节点。
- R9：页脚必须区分单测与批量，单测时展示当前节点及待测数量，批量时展示完整进度；入队、重复入队、取消和系统错误均有可见反馈。
- R10：测速中按 `Esc` 清空队列、取消当前流并停留在节点列表；空闲时按 `Esc` 才返回代理组列表。
- R11：不改变 daemon、CLI、IPC 路由、单次探测超时、批量并发数、批量范围或历史来源。

## Acceptance Criteria

- [x] AC1：使用不会自动完成的 fake stream 时，首次 `t` 启动当前节点；移动光标再按 `t` 不取消当前 context，而是按顺序入队并立即在页脚显示待测数量。
- [x] AC2：当前节点或已排队节点再次按 `t` 不重复入队，并显示明确反馈；移动光标和重复按键期间 TUI 状态转换不被阻塞。
- [x] AC3：当前单测完成后自动返回下一节点的 `tea.Cmd`，请求顺序与入队顺序一致；失败结果仍继续，系统性错误停止并清空队列。
- [x] AC4：单测或批量进行中按 `a` 会取消旧 context、清空队列并立即返回新的批量 command，请求为 `concurrency=5`、`limit=0`。
- [x] AC5：批量进行中按 `t` 会取消批量并立即返回所选节点的单测 command。
- [x] AC6：旧 generation 的 started、结果、完成、关闭和错误事件在替换后均被忽略，不会终止或覆盖新测速状态。
- [x] AC7：排队、模式切换和取消不会清空其他节点已完成结果；新结果继续逐项刷新。
- [x] AC8：测速中的 `Esc` 清空队列并取消但不离页，空闲时再次按 `Esc` 返回代理组列表。
- [x] AC9：窄终端页脚仍在宽度约束内表达当前模式、进度或队列数量，不与列表内容重叠。
- [x] AC10：现有节点历史、节点选择、daemon 重启和其他 TUI 测试继续通过；`go test ./...` 通过。

## Out of Scope

- 不并行运行多轮单测；单测队列严格串行。
- `t` 不自动移动列表光标，也不自动选择测速最快节点。
- 不持久化 TUI 队列或测速历史，不承诺 core 重启后保留结果。
- 不调整 CLI `mm node test` 的参数或输出。
